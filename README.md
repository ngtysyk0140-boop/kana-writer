# なぞって かこう — ひらがな・カタカナ 書き方アプリ

作成: 2026-10-25　対象: 幼稚園年長　目的: ていねいに文字が書けるようになる（読みは復習程度）
姉妹アプリ「よんで かいて 漢検」（`../kanji-reader`）と同じ骨格（毎日のゴール・スタンプカレンダー・バッジ・間隔反復・手書き・GitHub Pages 配信）。

公開URL: https://ngtysyk0140-boop.github.io/kana-writer/ （iPad Safari →「ホーム画面に追加」）

## 年長さん向けの設計
- 画面の文字はすべてひらがな。操作はタップと指書きだけ。色はパステル（ミント・ピーチ・ラベンダー）。
- ステージ: ひらがな／カタカナ それぞれ「あ・か」「さ・た」「な・は」「ま・や・ら・わ」「てんてん・まる」「ちいさい じ」。
- **なぞる**: 書き順データ（KanjiVG、教科書体の形）を薄く表示し、一画ずつ ● から順になぞる。各画で「書き始めの位置」「向き（逆向き検出）」「線の形（ガイド上をどれだけ通ったか）」「長さ」を判定し、ヒント（「●の ところから はじめよう」「ぎゃくむき だよ」「うすい せんの うえを ゆっくり」）を出す。3回失敗したらお手本を見せて次へ。字全体で★1〜3。判定の厳しさは設定で3段階。
- **かく**: 絵文字＋ことばの1文字を空欄にして、その字をガイドなしで書く。「できた！」でお手本を重ね、画数が合っていれば書き順ベースで★を付ける。最終判定は本人（保護者）の○△。
- **よむ**: 絵→ことばを選ぶ／ことば→絵を選ぶ（3択）。音声読み上げ（端末の日本語音声）付き。知っている字だけでできた言葉を優先。
- **きょう**: 期限の来た復習 → むずかしい字 → 新しい字（既定3字/日、なぞる→かく）＋読み3問。目標回数（既定8回）の円グラフ、14日カレンダー、バッジ。
- 反復: 漢検アプリと同じ（1→3→7→14→30→60→120日、間違えると翌日）。

## ファイル
- `index.html` 本体（依存なし）、`data/kana_strokes.js` 書き順（ひらがな・カタカナ184字）、`data/words.js` 絵文字つき単語（ひらがな約130・カタカナ約90）
- `tools/build_kana.py`（KanjiVG → kana_strokes.js。入力は ../kanji-reader/tools/src/kanjivg.xml）、`tools/build_site.py`（docs/ を生成）

更新手順: `python3 tools/build_site.py` → `git add -A && git commit && git push`
